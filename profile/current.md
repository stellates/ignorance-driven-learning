# Current Learning Profile

This file is intended to become a portable, user-owned summary of the learner's current knowledge state.

It should be updated from durable repository evidence such as:

- repeated questions
- confused concepts
- quiz mistakes
- recently learned topics
- long-unreviewed knowledge
- preferred explanation depth

Do not treat this file as ground truth about the person beyond the learning data in this repository.
